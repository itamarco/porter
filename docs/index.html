Installation

🍎 macOS

1

Download Porter

Download the latest DMG file from the Releases page

2

Install the App

Open the DMG file and drag Porter.app to your Applications folder

3

Launch Porter

Open Porter from your Applications folder

"App is damaged" Error?

If macOS shows an error saying Porter is "damaged and should be moved to the trash", this is because the app is not code-signed. This is a macOS Gatekeeper security feature.

Quick Fix: Run this command in Terminal:

xattr -cr /Applications/Porter.app

Alternative: Right-click Porter.app → Open → Click Open in the security dialog.

🪟 Windows

1

Download Porter

Download the latest .exe installer from the Releases page

2

Run the Installer

Double-click the downloaded .exe file to start the installation wizard

3

Launch Porter

Porter will be added to your Start Menu and Desktop

Windows Defender Warning

Windows may show a SmartScreen warning because the app is not code-signed. Click "More info" then "Run anyway" to proceed.

📋 Requirements

  • kubectl must be installed and configured
  • Valid kubeconfig file at ~/.kube/config (or %USERPROFILE%\.kube\config on Windows)
  • Access to at least one Kubernetes cluster
